# Project documentation

This documentation has been reorganized to serve both human developers and AI agents. It aims to explain not only how the project works, but also why it is designed this way.

## Purpose

This documentation helps a new contributor quickly understand:

- the architectural philosophy of the project,
- the separation between domain, application, and infrastructure,
- the development conventions to follow,
- the sensitive areas that should not be changed casually,
- and the best practices for evolving the system safely.
