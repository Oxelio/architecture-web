# Architecture Web — AI project context

Architecture Web is currently a TypeScript reference application centered on
identity and access management.

This file is a compact orientation aid, not an independent owner of method,
product, or architecture truth.

## Method

Architecture Web adopts the [Software Engineering Method](../method/README.md).
Resolve project-specific owners through the
[Project Method Profile](../project/project-method-profile.md).

## Architecture direction

The project follows project-owned constraints including:

- Domain-Driven Design;
- Clean Architecture;
- Hexagonal Architecture;
- autonomous bounded contexts;
- dependency inversion;
- explicit application contracts and ports;
- infrastructure-independent domain/application layers.

Read the canonical [Architecture principles](../project/architecture-principles.md)
and [Dependency rules](../architecture/dependency-rules.md) before architectural
work. Do not infer a preferred pattern from a historical exception.

## Working rule

For meaningful work, resolve the current Work Type, Workflow Depth, Activity,
Role, and focused Context Manifest before making normative decisions. AI may
recommend human-gated decisions but must not claim those gates have been crossed
without human authority.
