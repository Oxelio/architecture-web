# Documentation

La documentation est maintenue en deux éditions parallèles :

- [Français](fr/README.md)
- [English](en/README.md)

Les deux éditions décrivent la même architecture. Une modification de règle,
de contrat ou de parcours développeur **DOIT** être reportée dans les deux
éditions au cours du même changement.

Les documents privilégient les intentions et les règles durables. Les listes
exhaustives susceptibles d’évoluer renvoient vers leur source de vérité dans le
code ou vers l’interface OpenAPI générée par l’API.
