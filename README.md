# Architecture Web

Architecture Web is a TypeScript reference application for identity and access
management. The repository is used to design and demonstrate maintainable
software boundaries with Domain-Driven Design, Clean Architecture, Hexagonal
Architecture, explicit application ports, and replaceable infrastructure
adapters.

- [Project documentation](docs/README.md)
- [Project vision](docs/project/vision.md)
- [Architecture principles](docs/project/architecture-principles.md)
- [Delivery pipeline](docs/project/delivery-pipeline.md)
- Local OpenAPI UI: `http://localhost:3000/docs`

To run the project, see [Getting started](docs/development/getting-started.md).

## Documentation language

English is the canonical language for repository documentation, code
identifiers, public contracts, package names, and architectural records.
Discussion and exploratory work may happen in any language, but accepted
knowledge is integrated once into the canonical English documentation rather
than maintained as parallel translations.
