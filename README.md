# Architecture Web

Architecture Web is a TypeScript reference application for identity and access
management. The project demonstrates maintainable software boundaries with
Domain-Driven Design, Clean Architecture, Hexagonal Architecture, explicit
application ports, and replaceable infrastructure adapters.

The repository also contains a generic, architecture-neutral
[Software Engineering Method](docs/method/README.md) for proportional delivery,
AI role orchestration, context engineering, readiness, review, and validation.
Architecture Web adopts that method through its
[Project Method Profile](docs/project/project-method-profile.md).

## Documentation language

English is the canonical language for repository documentation, code
identifiers, public contracts, package names, and architectural records.
Discussion and exploratory work may happen in any language, but accepted
knowledge is integrated once into the canonical English documentation rather
than maintained as parallel translations.
